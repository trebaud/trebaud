<h1 align="center">@trebaud</h1>

<p align="center">
  Hey, I'm Thomas — a software developer in Montreal 🇨🇦
  <br>
  🔒 I ship code for the web in a secure and reliable way. Appsec, AI safety, and SRE are the three things I keep circling back to.
  <br>
  🕵️ I spend a lot of time on the defensive side: supply chain security, dependency auditing, threat modeling, and bug bounty triage.
  <br>
  🤖 Lately I build agent tooling — coding harnesses, reusable agent skills, and worktree-based agent orchestration.
  <br>
  🌱 Currently going deep on <b>agentic AI security</b>: prompt injection, tool-use abuse, untrusted skills, and what a real threat model for autonomous agents looks like.
  <br>
  🐹 Go for terminal tools, TypeScript for everything web, Neovim for all of it.
  <br>
  ✍️ I write at <a href="https://trebaud.com">trebaud.com</a> about appsec, caffeine, and questionable opinions.
  <br>
</p>

<h2 align="center">What I'm working on 🛠</h2>

<p align="center">
  🧰 <b>Agent tooling</b> — harnesses, skills, and worktree workflows that make coding agents actually useful
  <br>
  🐚 <b>Terminal-first UX</b> — TUIs and CLIs that are fast, keyboard-driven, and pleasant to live in
  <br>
  🛡 <b>Supply chain security</b> — auditing dependencies, catching typosquats, and hardening CI pipelines
  <br>
  🕳 <b>Agentic AI security</b> — auditing untrusted skills, prompt injection, and the new attack surface agents open up
  <br>
  🧠 <b>Local LLMs</b> — semantic search, RAG over code, and assistants that never leave the machine
</p>
